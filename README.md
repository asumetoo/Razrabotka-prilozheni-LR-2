**Кафедра:** Промышленная логистика (ИБМ-3)

**Дисциплина:** Разработка интернет-приложений

Продолжение ЛР1: вычисления в калькуляторе с сохранением оформления РЖД.

## Запуск
Откройте `index.html` двойным щелчком, затем «Открыть калькулятор».

## Возможности
Сложение, вычитание, умножение, деление, очистка, удаление символа, смена знака, проценты, квадрат, корень, факториал, ввод 000, M+ и M−, изменение цветов. Индивидуальная операция — обратное число `1/x`. Ввод ограничен шириной дисплея; длинный результат сокращается с многоточием.

## Файлы
`index.html` — главная, `calculator_1.html` — калькулятор, `style_1.css` — стили, `script_1.js` — вычисления.
